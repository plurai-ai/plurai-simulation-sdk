# Security policy

Report a vulnerability privately through GitHub's private vulnerability reporting: open the repository's **Security**
tab and choose **Report a vulnerability**. Please do not open a public issue or pull request for it.

Include the affected version, a description of the impact and the steps to reproduce it. Reports are acknowledged on a
best-effort basis, and a fix ships as a new release of `plurai-simulation-sdk`.

Only the latest release is supported.
